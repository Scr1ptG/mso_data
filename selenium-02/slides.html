DOM

Страница — это дерево тегов

Наведите мышь на строку справа — подсветится элемент слева. Selenium видит именно это дерево, а не картинку.

Шпаргалка: 7 правил хватит на всё

3 мин. Самое важное — разница «пробел» и «без пробела». a._topnews — один элемент с двумя признаками; a ._topnews — внутри a.

Главная схема

Группа → каждая новость в группе

driverвся страница
→
group.topnews
→
cardsa._topnews × 8
→
ссылка · заголовок · время
group = driver.find_element(By.CLASS_NAME, "topnews")
cards = group.find_elements(By.CSS_SELECTOR, "a._topnews")     # ищем ВНУТРИ group #!
news = []
for card in cards:
    link = card.get_attribute("href")                          # атрибут самой карточки
    title = card.find_element(By.CSS_SELECTOR, ".card-big__title, .card-mini__title").text
    time = card.find_element(By.TAG_NAME, "time").text
    news.append({"link": link, "title": title, "time": time})
5 мин. Разберите построчно. Почему не driver.find_elements(".card-mini"): на странице есть ещё карточки рубрик — получим лишнее. Это и есть «нахождение группы новостей + каждой новости в этой группе» из задания LXP.
Что достать

Текст, атрибут, тег внутри

.text

Видимый текст элемента и всех его потомков. Скрытый элемент даст пустую строку.

.get_attribute("href")

Значение атрибута. Для href Selenium сразу отдаёт полную ссылку: /news/… → https://lenta.ru/news/…

el.find_element(...)

Поиск внутри элемента. Так берём заголовок и время из одной карточки, а не из всей страницы.

Если .text пустой, а в F12 текст есть — элемент скрыт или ещё не загрузился. Попробуйте get_attribute("textContent") или подождите (слайд 12).

WebDriverWait — проверяет условие каждые полсекунды и идёт дальше, как только оно выполнилось.

from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

wait = WebDriverWait(driver, 10)   # ждать не дольше 10 с
driver.find_element(By.ID, "loadmore").click()
wait.until(EC.invisibility_of_element_located(
    (By.ID, "loadmore")))           # двойные скобки! #!
4 мин. Двойные скобки — частая ошибка: условию передаётся кортеж (By, "селектор"). Другие условия: visibility_of_element_located, element_to_be_clickable, presence_of_all_elements_located.
Формы

Напечатать, выбрать, нажать

from selenium.webdriver.support.ui import Select

field = driver.find_element(By.NAME, "login")
field.clear()                    # очистить
field.send_keys("student")       # напечатать
driver.find_element(By.ID, "submit").click()

# выпадающий список <select>
op = Select(driver.find_element(By.ID, "op"))
op.select_by_visible_text("умножить")
op.select_by_value("mul")
op.select_by_index(2)

В старой презентации пример с Select написан на Java (new Select(el), selectByValue). В Python так, как слева.

Вежливый парсинг

Правила, чтобы не забанили

⏱ Пауза между страницами: time.sleep(0.5–1). 30 студентов без пауз — это маленькая DDoS-атака.

🤖 robots.txt: lenta.ru/robots.txt — что сайт просит не обходить.

🔐 Только свои аккаунты и только тестовые для учёбы.

🙅 Персональные данные (телефоны, профили людей) не собираем: это закон о персональных данных.

📦 Есть API? Берите API: быстрее и честнее, чем Selenium.

🧪 Отлаживаем на полигоне, на настоящий сайт идём с готовым кодом.
