# Методы сбора и обработки данных

Материалы к дисциплине «3235.МСО.F.26О Методы сбора и обработки данных» (IThub).

**Сайт:** https://scr1ptg.github.io/mso_data/

## Selenium
| Папка | Что внутри |
|---|---|
| [`polygon`](polygon) | «Новости Полигона»: учебный сайт для тренировки парсинга. Разметка как у lenta.ru, есть рубрики с кнопкой «Показать ещё», форма входа и калькулятор. Работает без интернета |
| [`selenium-02`](selenium-02) | Занятие «Парсинг новостного сайта»: `slides.html`, задания `practice/`, квиз `quiz.json`, архив для студентов `selenium_praktika.zip` |
| [`shared`](shared) | Движок HTML-презентаций (стрелки — листать, F — во весь экран, N — заметки) |

Все новости на полигоне выдуманы. Автопроверки заданий опираются на данные из `polygon/assets/data.js`: если меняете тексты, поменяйте ответы в `selenium-02/practice/common.py`.
